Writing, where the credential allows it.

Tick a task off — in the list or in the note it is written in — add a task under a project heading, and capture a thought into a scratchpad from the share sheet, a launcher shortcut or the widget. Each one is a commit, attributed to the name and email set in Settings.

Every write is gated on what the host says the credential may do: a read-only deploy key or a Contents: read-only token leaves the checkboxes inert rather than failing at the push. An edit made with no signal is kept and sent with the next sync, and it is re-applied to whatever the file says by then rather than overwriting it.
