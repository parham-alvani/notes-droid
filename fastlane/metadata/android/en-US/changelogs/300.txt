Background sync now actually runs.

The schedule was written but nothing ever registered it, so the vault only refreshed when you tapped. It is now registered when the app starts, kept in step with the settings, and can be switched off or set to run every 1, 3, 6, 12 or 24 hours, optionally on Wi-Fi only.

A scheduled sync no longer asks Android for a foreground service. An app in the background is not allowed to start one, so every scheduled run reported an error for something it never needed; a tap still gets one, because a tap happens while the app is in front.

Settings also names battery optimisation when it is on, since on a phone that dozes aggressively that is the setting that decides whether any of this happens.
